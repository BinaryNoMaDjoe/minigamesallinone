# Skill：skill-design-system（应用 Inked Kinetic 设计规范）

> **版本**：v0.1
> **变更记录**：v0.1 初稿（2026-08-15）

## 触发条件

任何涉及颜色、字体、间距、纹理、阴影、组件样式、动效的 UI 工作。

## 前置阅读

`docs/design-language.md` 全文（重点：§2 色彩、§3 字体、§5–§9 形状/纵深/纹理/组件/动效、附录 A/B/C）。

## 规则

1. **取色**：只允许引用令牌（附录 A 亮色 / C 暗色）。禁止新造 hex；需要新色 → 走生长流程（docs/process/evolution.md）提提案
2. **纹理**：用附录 B 配方类（`halftone-bg` / `speed-lines` / `comic-border` / `comic-shadow(-red/-blue)` / `comic-bubble`），颜色令牌化后不得改配方结构
3. **描边即纵深**：按钮 2px、气泡 3px、卡片/弹窗 4px（§6）
4. **硬阴影**：6px×6px 纯色错位；按压态位移 1px 去阴影（§6）
5. **组件对照 §8**：新组件先查 §8 是否有规格；没有 → 提"组件规格生长"提案，不自行发明
6. **动效**：按 §9 时长表；禁止弹性/漂浮动画；必须实现 `prefers-reduced-motion` 降级
7. **明暗双验**：改完在 `html.dark` 下复查 §2.5 九条转译规则（白墨线、深阴影、网点降档等）

## 检查清单

- [ ] 所有色值来自令牌表，键名一致
- [ ] 亮/暗两套都验证过
- [ ] 纹理层 `pointer-events: none`
- [ ] 焦点态可见（蓝 outline）
- [ ] 动效有 reduced-motion 降级
- [ ] 未发明 §8 之外的新组件规格（或已提案）

## 红线

- 色值、字体、间距不得自造
- 不得绕过令牌直接写色值
- 修改令牌/配方 → 必须同步更新 design-language.md 并走确认
