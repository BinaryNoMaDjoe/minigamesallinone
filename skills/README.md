# skills/ — 项目级技能索引

> **版本**：v0.1
> **变更记录**：v0.1 初稿（2026-08-15）

## 是什么

技能 = 一份可复用的**工作流程定义**（Markdown 文档）：触发条件 + 前置阅读 + 步骤 + 检查清单 + 输出 + 红线。AI 会话在任务命中触发条件时，**先读技能全文再动手**；宿主环境若提供技能注册机制，可按同名技能注册。

所有技能共同遵守 `AGENTS.md` 红线；技能本身可随项目生长（修订需更新版本与变更记录）。

## 索引

| 技能 | 文件 | 触发条件 |
|---|---|---|
| 新增游戏 | `skill-add-game.md` | 用户要求新增/开发一个小游戏 |
| 设计系统应用 | `skill-design-system.md` | 任何涉及颜色/字体/纹理/组件样式/动效的 UI 工作 |
| 双语文案 | `skill-i18n.md` | 新增/修改任何用户可见文案 |
| 代码审查 | `skill-code-review.md` | 提交前自检、审查变更 |

## 使用约定

- 一个任务可触发多个技能，全部执行对应检查清单
- 检查清单结果必须在汇报中体现（勾选 + 未过项说明）
- 技能发现不适用/过时 → 提生长提案（docs/process/evolution.md），不私自改
