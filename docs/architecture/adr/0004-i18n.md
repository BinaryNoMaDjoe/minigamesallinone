# ADR-0004：轻量自研 i18n

- **状态**：accepted
- **日期**：2026-08-15

## 背景

用户要求界面语言中英双语。项目规模是一个多游戏合集前端，文案量集中在公共壳层与各游戏元数据，暂不需要成熟的重量级 i18n 框架的全部能力。

## 决策

- 自研轻量方案：typed key 文案表（`src/i18n/`，zh/en 两个语言文件必须同步修改）+ React Context + localStorage 语言记忆，默认跟随浏览器语言、可手动切换
- 游戏元数据（name / description）以 `{ zh, en }` 结构放在 manifest 中，大厅按当前语言取值
- 公共壳层（大厅、GameWindow 控制条、气泡、页脚）文案一律走文案表，禁止硬编码
- 键名规范与检查清单见 `skills/skill-i18n.md`

## 理由

- 需求边界明确，自研成本低且类型安全可控（决策记录 #9，用户未反对默认项）
- manifest 本身就是结构化双语数据，自研方案与其天然贴合
- 未来若文案量失控，可迁移成熟框架——文案表结构即迁移边界

## 后果

- 约束：zh/en 同步是硬性纪律，单语言提交视为阻断级问题
- 约束：文案膨胀需按中文最长情形验收（design-language.md §3.4）
