# 游戏级设计规范 · 连连看（Lianliankan · 二次元几何风）

> **版本**：v0.1
> **变更记录**：v0.1 初稿（2026-08-15，随实现建立）
> **适用范围**：仅本游戏窗内（`src/games/lianliankan/`）。窗外与窗框遵循网页级规范 `docs/design-language.md`。
> **依据**：用户指令"连连看使用二次元风格化的美术风格，图形用几何图形诸如方圆三角等，尽量做完整"（2026-08-15）。

## 1. 定位

- **二次元（anime）风格化**：柔粉渐变天空背景、圆角卡片、柔和投影、几何图形上绘制"颜文字脸"（大眼 + 腮红 + 微笑），配色为马卡龙色系
- 与网页级"锐利硬边漫画风"刻意区分：本游戏窗内允许**圆角、柔和渐变与软阴影**（游戏级规范自主权）
- 图形 = 七种几何形状：**圆、方、三角、菱形、五边形、六边形、星形**

## 2. 玩法规则（本文件即实现依据）

1. **棋盘**：默认 8 列 × 6 行 = 48 格 = 24 对；每关棋盘重新生成
2. **匹配**：点击两个**相同图形**，若两者间的连线在棋盘空格内**拐角 ≤ 2**（可直线/一拐/二拐），即消除
3. **生成**：形状数按关卡递增（§6）；每种形状数量必为偶数（成对生成，洗牌打散）
4. **计分**：消除一对 `100 + (连击数-1) × 20`；连续消除递增连击，选中不同形状/使用道具则连击清零；过关时间奖励 `剩余秒数 × 5`
5. **道具**（每关各 3 次）：**提示**（高亮一对可消除图形）、**洗牌**（打散剩余图形，连击清零）
6. **死局自动洗牌**：场上无任何可消除组合时自动洗牌（免费、不扣次数）
7. **过关**：限时内清空棋盘 → 本关完成（+时间奖励）→ 下一关；第 5 关完成 → **通关**
8. **失败**：时间耗尽 → GAME OVER（结算分数）
9. 分数实时经 `callbacks.onScore` 上报壳层，由壳层统一提交 ScoreService（ADR-0005）；主菜单展示最高分

**未实现（明确排除，避免脑补）**：音效、成就系统、道具商店、撤销。

## 3. 布局（逻辑画布 480 × 360，比例 4:3）

| 区域     | 位置                   | 内容                                         |
| -------- | ---------------------- | -------------------------------------------- |
| 状态区   | 左上三行 (y=12/34/56)  | LEVEL / TIME / SCORE（时间 ≤10s 变红）       |

- 匹配特效：连接线（圆角折线，350ms 淡出）+ 两端星屑粒子

## 5. 控件

- **鼠标/触屏**：点击图形选择/消除；点击道具按钮使用道具
- **键盘**：回车/空格——menu 开始、paused 继续、over 重新挑战；P 暂停/继续
- **壳层**：控制条随阶段适配（ADR-0007）：menu 隐藏暂停/重开；playing/paused 显示暂停/继续；over 隐藏暂停保留重开
- 道具与菜单按钮为真实 `<button>`（键盘可达，双语 aria/文本）

## 7. 阶段状态机（ADR-0007、决策 #24）

| 阶段             | 画面                                               | 可选动作                                  |
| ---------------- | -------------------------------------------------- | ----------------------------------------- |
| `menu`           | 面板：标题 + 最高分 + 开始游戏                     | [开始游戏] / 回车·空格                    |
| `playing`        | 游戏进行；过关瞬间冻结显示"第 N 关完成 + 时间奖励" | [下一关] / 玩法操作                       |
| `paused`         | 面板：已暂停                                       | [继续] [重新开始] [结束游戏] [返回主菜单] |
| `over`（时间到） | 面板：时间到 + 本局分数                            | [重新挑战] [返回主菜单]                   |
| `over`（通关）   | 面板：通关 + 总分                                  | [再来一次] [返回主菜单]                   |

- 过关冻结为引擎内部状态（`frozen`），合约阶段保持 `playing`（壳层按钮不受干扰）
- `结束游戏`：从 paused 结束本局 → over（时间到样式，保留成绩）
- `返回主菜单`：清空棋盘与成绩 → menu

## 8. 工程结构与测试（决策 #25）

- `engine.ts`：纯逻辑（棋盘生成/路径寻路/计分连击/道具/关卡/阶段机），无 DOM，可注入随机源；`findPath` 导出供测试
- `engine.test.ts`：node 直跑冒烟测试——生成偶数性、寻路（直线/一拐/二拐/阻断）、消除计分、连击、提示、通关（2×2 小棋盘连过 5 关）、超时判负
- `shapes.ts`：形状色板与关卡配置；`Game.tsx`：Canvas 渲染 + DOM 浮层与道具按钮
