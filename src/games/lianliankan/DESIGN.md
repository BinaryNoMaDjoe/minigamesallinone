# 游戏级设计规范 · 连连看（Lianliankan · 星露谷式像素风）

> **版本**：v0.2
> **变更记录**：v0.1 初稿（2026-08-15，随实现建立，二次元马卡龙风）→ v0.2（2026-08-15，用户指令）：整体重做为**星露谷式像素风**——16×16 像素精灵系统（光栅化几何图形 + 像素脸部）、草地天空场景、硬边深棕 UI + Press Start 2P 像素字体；玩法规则/关卡/引擎不变
> **适用范围**：仅本游戏窗内（`src/games/lianliankan/`）。窗外与窗框遵循网页级规范 `docs/design-language.md`。
> **依据**：用户指令"连连看使用二次元风格化的美术风格"（2026-08-15）与"风格请换成像素风，参考星露谷，界面 UI 做精致"（2026-08-15）。

## 1. 定位

- **星露谷式像素风**：温暖泥土色调、块状像素、深色描边 + 高光/阴影双层明暗、硬边 UI；场景为天空 + 草地 + 木框棋盘
- 图形 = 七种几何形状：**圆、方、三角、菱形、五边形、六边形、星形**，全部由 16×16 像素精灵呈现（`pixel.ts` 光栅化：圆/方/菱形解析式，三角/五边/六边/星射线法多边形），带**像素脸部**（眼 ×2、腮红 ×2、嘴 ×2，仅落于图形内部）
- 像素纪律：`image-rendering: pixelated` + `imageSmoothingEnabled=false`；绘制坐标以整数像素为准；禁止抗锯齿形状、渐变与软阴影

## 2. 玩法规则（本文件即实现依据，v0.2 未变）

1. **棋盘**：默认 8 列 × 6 行 = 48 格 = 24 对；每关棋盘重新生成
2. **匹配**：点击两个**相同图形**，若两者间的连线在棋盘空格内**拐角 ≤ 2**（可直线/一拐/二拐），即消除
3. **生成**：形状数按关卡递增（§6）；每种形状数量必为偶数（成对生成，洗牌打散）
4. **计分**：消除一对 `100 + (连击数-1) × 20`；连续消除递增连击，选中不同形状/使用道具则连击清零；过关时间奖励 `剩余秒数 × 5`
5. **道具**（每关各 3 次）：**提示**（高亮一对可消除图形）、**洗牌**（打散剩余图形，连击清零）
6. **死局自动洗牌**：场上无任何可消除组合时自动洗牌（免费、不扣次数，循环至有解）
7. **过关**：限时内清空棋盘 → 本关完成（+时间奖励）→ 下一关；第 5 关完成 → **通关**
8. **失败**：时间耗尽 → GAME OVER（结算分数）
9. 分数实时经 `callbacks.onScore` 上报壳层，由壳层统一提交 ScoreService（ADR-0005）；主菜单展示最高分

**未实现（明确排除，避免脑补）**：音效、成就系统、道具商店、撤销。

## 3. 布局（逻辑画布 480 × 360，比例 4:3）

| 区域     | 位置                   | 内容                                                  |
| -------- | ---------------------- | ----------------------------------------------------- |
| HUD      | 左上三行 (y=12/34/56)  | LEVEL / TIME / SCORE（8px 像素字体，时间 ≤10s 变红）  |
| 棋盘     | (16,68) 起，8×6 格     | 格 32px（16×16 精灵 ×2）+ 间距 2px；4px 木框 + 面板底 |
| 空格占位 | 空格中心               | 6×6 深色小方块                                        |
| 道具区   | 右列 (x≥300，DOM 按钮) | HINT x3 / SHUFFLE x3 / PAUSE（像素按钮）              |
| 连击提示 | 棋盘左下 (20,300)      | COMBO xN（连击 ≥2，黄色）                             |
| 阶段浮层 | 覆盖整个画布           | menu / paused / over / 过关 / 通关面板（§7）          |

- 场景：天空（上）+ 草地（y≥244，含深色草纹）；云朵为白色像素块
- 匹配特效：黄色像素折线（3px，350ms 淡出）+ 端点白块 + 星屑方块粒子
- 选中高亮：黄色 2px 框脉冲；提示高亮：白色 2px 框脉冲

## 5. 控件

- **鼠标/触屏**：点击图形选择/消除；点击道具按钮使用道具
- **键盘**：回车/空格——menu 开始、paused 继续、over 重新挑战；P 暂停/继续
- **壳层**：控制条随阶段适配（ADR-0007）
- 道具与菜单按钮为真实 `<button>`（键盘可达，双语 aria/文本）

## 7. 阶段状态机（ADR-0007、决策 #24，v0.2 未变）

| 阶段             | 画面                                               | 可选动作                                  |
| ---------------- | -------------------------------------------------- | ----------------------------------------- |
| `menu`           | 面板：标题 + 最高分 + 开始游戏                     | [开始游戏] / 回车·空格                    |
| `playing`        | 游戏进行；过关瞬间冻结显示"第 N 关完成 + 时间奖励" | [下一关] / 玩法操作                       |
| `paused`         | 面板：已暂停                                       | [继续] [重新开始] [结束游戏] [返回主菜单] |
| `over`（时间到） | 面板：时间到 + 本局分数                            | [重新挑战] [返回主菜单]                   |
| `over`（通关）   | 面板：通关 + 总分                                  | [再来一次] [返回主菜单]                   |

- 过关冻结为引擎内部状态（`frozen`），合约阶段保持 `playing`

## 8. 工程结构与测试（决策 #25）

- `engine.ts`：纯逻辑（棋盘生成/寻路/计分连击/道具/关卡/阶段机），node 直跑可测；`findPath` 导出
- `pixel.ts`：16×16 像素精灵光栅化（纯函数，可测）；`pixel.test.ts`：7 精灵尺寸/字符集/非空/脸部像素
- `engine.test.ts`：生成偶数性、寻路 4 情形、计分连击、提示、2×2 连过 5 关通关、超时判负
- `Game.tsx`：Canvas 渲染 + DOM 浮层与道具按钮

## 9. UI 精致度要求（像素风）

- 面板：米色底 + 3px 深棕描边 + 4px 硬阴影（无圆角）
- 按钮：2px 深棕描边 + 2px 硬阴影；按压位移 2px 且阴影消失（像素"按下"）
- 字体：`Press Start 2P`（@fontsource 自托管，决策 #26 配套）；中文回退 `var(--font-label-bold)` 栈
- 禁用态：45% 透明度；所有文案双语
