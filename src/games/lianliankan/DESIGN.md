## 1. 定位

- **星露谷风物像素**：温暖泥土色调、块状像素、深色描边 + 高光/阴影双层明暗、硬边 UI；场景为天空 + 草地 + 木框棋盘（六大关各自换场景，§4.1）
- **美术资产声明（重要）**：全部精灵为**按星露谷风格原创绘制的 16×16 像素画**（`pixel.ts` 程序化构图，非官方游戏素材、非网络下载）。星露谷物语官方美术版权属 ConcernedApe，本项目仅学习研究、禁止商用与传播（根目录 LICENSE），**不得内嵌他人版权素材**；如需官方贴图，须由素材权利人授权后另行接入
- **封面**：横版 `cover.svg`（3:2，卡片头图）与竖版 `cover-portrait.svg`（2:3，大厅 Hero 面板铺满，决策 #28），构图与取色同 §4 色板
- 像素纪律：`image-rendering: pixelated` + `imageSmoothingEnabled=false`；绘制坐标以整数像素为准；禁止抗锯齿形状、渐变与软阴影

## 2. 玩法规则（本文件即实现依据）

1. **棋盘**：默认 8 列 × 6 行 = 48 格 = 24 对；每关棋盘重新生成
2. **匹配**：点击两个**相同元素**，若两者间的连线在棋盘空格内**拐角 ≤ 2**（可直线/一拐/二拐），即消除；消除连线特效的路径**必须包含两个被消除元素本身**（起点=首点元素中心，终点=次点元素中心，§10 缺陷 #1）
3. **生成**：元素按关卡递增（§6 关卡表）；每种元素数量必为偶数（成对生成，洗牌打散）
4. **计分**：消除一对 `100 + (连击数-1) × 20`；连续消除递增连击，选中不同元素/使用道具则连击清零；过关时间奖励 `剩余秒数 × 5`
5. **道具**（每关各 3 次）：**提示**（高亮一对可消除元素）、**洗牌**（打散剩余元素，连击清零）
6. **死局自动洗牌**：场上无任何可消除组合时自动洗牌（免费、不扣次数，循环至有解）
7. **过关**：限时内清空棋盘 → 本关完成（+时间奖励）→ 下一关；**第 18 关完成 → 通关**（共 6 大关 × 3 小关）
8. **失败**：时间耗尽 → GAME OVER（结算分数）
9. 分数实时经 `callbacks.onScore` 上报壳层，由壳层统一提交 ScoreService（ADR-0005）；主菜单展示最高分
10. **大关（章节）**：`第 N 大关 = 第 3N-2 关至第 3N 关`。每大关使用独立元素集（6 种）与场景配色（§4）；进入新大关时棋盘上方显示大关横幅提示

**未实现（明确排除，避免脑补）**：音效、成就系统、道具商店、撤销、续关存档。

## 5. 控件

- **鼠标/触屏**：点击元素选择/消除；点击道具按钮使用道具；画布 `touch-action: none`、道具与浮层按钮 ≥40px 高（§4.3）
- **键盘**：回车/空格——menu 开始、paused 继续、over 重新挑战、**过关冻结面板进入下一关**（§10 缺陷 #4）；P 暂停/继续
- **壳层**：控制条随阶段适配（ADR-0007）
- 道具与菜单按钮为真实 `<button>`（键盘可达，双语 aria/文本）

## 6. 关卡表（18 关 = 6 大关 × 3 小关）

- 第 n 关（1–18）：大关 `chapterOf(n) = ⌊(n-1)/3⌋ + 1`；元素数 `4 + (n-1) mod 3`（即每大关内 4/5/6 种）；时限 `150 - 3×(n-1)` 秒（第 18 关 99 秒）

## 7. 阶段状态机（ADR-0007、决策 #24，未变）

| 阶段             | 画面                                               | 可选动作                                  |
| ---------------- | -------------------------------------------------- | ----------------------------------------- |
| `menu`           | 面板：标题 + 最高分 + 开始游戏                     | [开始游戏] / 回车·空格                    |
| `playing`        | 游戏进行；过关瞬间冻结显示"第 N 关完成 + 时间奖励" | [下一关] / 回车·空格 / 玩法操作           |

- 过关冻结为引擎内部状态（`frozen`），合约阶段保持 `playing`

## 8. 工程结构与测试（决策 #25）

- `engine.ts`：纯逻辑（棋盘生成/寻路/计分连击/道具/关卡/大关/阶段机），node 直跑可测；`findPath`、`chapterOf` 导出
- `themes.ts`：6 大关主题数据（双语名 + 场景色板 + 元素集），纯数据可测
- `pixel.ts`：36 个 16×16 像素精灵构图（纯函数，可测）；`pixel.test.ts`：36 精灵尺寸/字符集/非空/脸部像素
- `engine.test.ts`：生成偶数性、寻路 4 情形、计分连击、提示、大关推导、连线路径含起点（缺陷 #1 回归）、2×2 连过 18 关通关、超时判负
- `Game.tsx`：Canvas 渲染（分大关场景）+ DOM 浮层与道具按钮

## 9. UI 精致度要求（像素风）

- 面板：米色底 + 3px 深棕描边 + 4px 硬阴影（无圆角）；随大关换 `--llk-*` 配色
- 按钮：2px 深棕描边 + 2px 硬阴影；按压位移 2px 且阴影消失（像素"按下"）；**主按钮 = 木框底 + 主题连线色文字**（`frame` 底 + `line` 文字，亮暗主题均具足够对比）
- 字体：`Press Start 2P`（@fontsource 自托管，决策 #26 配套）；DOM 中文回退 `var(--font-label-bold)` 栈；**画布侧无法引用 CSS 变量，字体串显式追加中文回退栈**（Noto Sans SC / PingFang SC / Microsoft YaHei）
- 禁用态：45% 透明度；所有文案双语
