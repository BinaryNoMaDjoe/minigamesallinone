## 1. 定位

- 经典俄罗斯方块的**像素/街机风**实现：低分辨率逻辑画布 + `image-rendering: pixelated`，块状色块 + 内嵌 1px 高光/阴影，追求 8-bit 质感
- 窗内为**固定画板**：不随网页明暗主题切换（像素游戏氛围恒定），但所有取色给出出处（见 §4 色板）

## 2. 玩法规则（本文件即实现依据）

1. **棋盘**：10 列 × 20 行；7 种方块（I O T S Z J L）
2. **随机**：7-bag——7 种方块洗牌成一袋依次发放，袋空重洗（保证分布均匀、不连续重复）
3. **生成**：方块自棋盘顶行上方（y=-1）出现；生成即碰撞 → 游戏结束
4. **旋转**：顺时针旋转（↑ / X 键）；碰撞时尝试简化踢墙偏移 `[0,0] [-1,0] [+1,0] [0,-1] [-2,0] [+2,0]`，取首个不碰撞位置
5. **下落**：重力按等级加速（见 §6）；↓ 软降每格 +1 分；空格硬降每格 +2 分并立即锁定
6. **消行**：满行消除，上方整体下移；一次消除 1/2/3/4 行计 `100/300/500/800 × 等级`（单次计分按 4 行封顶防御）
7. **等级**：`等级 = 1 + ⌊行数 / 10⌋`
8. **结束**：方块在棋盘顶部（y<0）锁定 → GAME OVER（结算画面显示本局分数/等级/行数）
9. 分数实时经 `callbacks.onScore` 上报壳层，由壳层统一提交 ScoreService（游戏不直写存储，ADR-0005）；主菜单展示最高分（经 scoreService 读取）

**未实现（明确排除，避免脑补）**：Hold 暂存、幽灵块开关、音效、Combo/T-Spin 提示、对战模式。

## 3. 布局（逻辑画布 320 × 448，比例 5:7）

| 区域       | 位置                        | 内容                                                   |
| ---------- | --------------------------- | ------------------------------------------------------ |
| 顶部条     | y 8..56                     | 左：TETRIS 标题（12px 像素字体）；右：SCORE 标签与数值 |
| 棋盘       | (8,64) 起，160×320          | 10×20 格，格 16px，2px 白墨描边                        |
| NEXT 框    | (176,64) 136×96             | 深底 + 白墨描边；标签 + 4×4 迷你预览（格 12px，居中）  |
| LEVEL 框   | (176,168) 136×56            | 深底 + 描边；标签 + 数值                               |
| LINES 框   | (176,232) 136×56            | 深底 + 描边；标签 + 数值                               |
| 键位提示框 | (176,296) 136×88            | 四行 8px 像素文字（移动/旋转/硬降/暂停）               |
| 触屏控件   | 底部悬浮（画布 376px 以下） | ◀ ▼ ▶ 一组；⏸ ⟳ ⇓ 一组；窄窗换行收窄不裁切（§4.3）     |
| 阶段浮层   | 覆盖整个画布（z 高于控件）  | menu/paused/over 菜单面板（§7）                        |

- 画布以 CSS 拉伸至容器（容器比例由 manifest 声明），`image-rendering: pixelated` + `imageSmoothingEnabled=false` 保持像素锐利
- 触屏控件与浮层面板随容器宽度紧凑化（容器查询 ≤420px / ≤200px）：面板取消最小宽、控件允许换行且按钮保持 ≥40px；≤200px 档按钮宽收窄至 32px（高度恒 40px，§4.3 窄窗例外）——横屏手机（如 740×360）下窗口仅约 115px 宽，6 键 40px 无法几何共存，两行控件叠加覆盖棋盘下缘属已确认取舍；任何窗口宽度下不裁切出界（§4.3）
- 幽灵块：当前方块落点以半透明轮廓显示（alpha 0.18）
- **像素字体**：`Press Start 2P`（@fontsource 自托管）用于画布 HUD 与菜单面板；中文回退 `var(--font-label-bold)` 栈

## 5. 控件

- **键盘**：←→ 移动；↓ 软降；↑ / X 旋转；空格硬降；P 暂停/继续；回车——menu 开始 / paused 继续 / over 再来一局。方向键与空格 `preventDefault`（防页面滚动）
- **触屏**：画布下方 DOM 按钮（◀ ▼ ▶ / ⏸ ⟳ ⇓），按钮 ≥40px 高（§4.3）；画布 `touch-action: none`（§4.3）、按钮 `touch-action: manipulation`（防双击缩放）
- **壳层**：控制条随阶段适配（ADR-0007）：menu 隐藏暂停/重开；playing/paused 显示暂停/继续；over 隐藏暂停保留重开
- 阶段浮层菜单按钮为真实 `<button>`（键盘可达，双语 aria/文本）

## 7. 阶段状态机（ADR-0007、决策 #24）

| 阶段      | 画面                                      | 可选动作                                  |
| --------- | ----------------------------------------- | ----------------------------------------- |
| `menu`    | 像素面板：标题 TETRIS + 最高分 + 开始游戏 | [开始游戏] / 回车·空格                    |
| `playing` | 游戏进行（触屏控件可见）                  | 玩法操作 / P 或 ⏸ 暂停                    |
| `paused`  | 面板：已暂停                              | [继续] [重新开始] [结束游戏] [返回主菜单] |
| `over`    | 面板：GAME OVER + 本局分数/等级/行数      | [再来一局] [返回主菜单] / 回车再来一局    |

- 阶段变化经 `callbacks.onPhase` 通知壳层；`mount` 后主动上报一次初始阶段
- `结束游戏`：从 paused 结束本局 → over 结算画面（保留成绩）
- `返回主菜单`：清空棋盘与本局成绩 → menu

## 8. 工程结构与测试（决策 #25）

- `engine.ts`：纯逻辑（棋盘/7-bag/旋转踢墙/消行计分/等级/阶段机），无 DOM，可注入随机源
- `engine.test.ts`：node 直跑冒烟测试——首块生成、边界、消行计分（含 NaN 防御回归）、顶出判负、7-bag、状态机（16 断言全绿）
- `Game.tsx`：渲染与输入层（Canvas + DOM 浮层）

## 9. 无障碍与生命周期

- 所有菜单/控件为真实 `<button>`，键盘可达；焦点在按钮上时全局快捷键让位（回车触发点击）
- 销毁时清理：rAF、window keydown、DOM 节点全部移除（skill-code-review 维度 3/12）
- 高频回调（onScore）不触发壳层 effect 重建（教训已写入 skill-code-review 维度 12）
