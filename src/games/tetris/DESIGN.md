# 游戏级设计规范 · 俄罗斯方块（Tetris · 像素风）

> **版本**：v0.2
> **变更记录**：v0.1 初稿（2026-08-15，首个正式游戏，随实现建立）→ v0.2（2026-08-15，用户指令）：画布状态区增加 SCORE 显示
> **适用范围**：仅本游戏窗内（`src/games/tetris/`）。窗外与窗框遵循网页级规范 `docs/design-language.md`。
> **依据**：用户指令"做一个像素风格化的俄罗斯方块，从方案到落地完全执行"（2026-08-15）。

## 1. 定位

- 经典俄罗斯方块的**像素/街机风**实现：低分辨率逻辑画布 + `image-rendering: pixelated`，块状色块 + 内嵌 1px 高光/阴影，追求 8-bit 质感
- 窗内为**固定画板**：不随网页明暗主题切换（像素游戏氛围恒定），但所有取色给出出处（见 §4 色板）

## 2. 玩法规则（本文件即实现依据）

1. **棋盘**：10 列 × 20 行；7 种方块（I O T S Z J L）
2. **随机**：7-bag——7 种方块洗牌成一袋依次发放，袋空重洗（保证分布均匀、不连续重复）
3. **生成**：方块自棋盘顶行上方（y=-1）出现；生成即碰撞 → 游戏结束
4. **旋转**：顺时针旋转（↑ / X 键）；碰撞时尝试简化踢墙偏移 `[0,0] [-1,0] [+1,0] [0,-1] [-2,0] [+2,0]`，取首个不碰撞位置
5. **下落**：重力按等级加速（见 §6）；↓ 软降每格 +1 分；空格硬降每格 +2 分并立即锁定
6. **消行**：满行消除，上方整体下移；一次消除 1/2/3/4 行计 `100/300/500/800 × 等级`
7. **等级**：`等级 = 1 + ⌊行数 / 10⌋`
8. **结束**：方块在棋盘顶部（y<0）锁定 → GAME OVER；回车或壳层 RESTART 重开
9. 分数实时经 `callbacks.onScore` 上报壳层，由壳层统一提交 ScoreService（游戏不直写存储，ADR-0005）

**未实现（明确排除，避免脑补）**：Hold 暂存、幽灵块开关、音效、Combo/T-Spin 提示、对战模式。

## 3. 布局（逻辑画布 320 × 448，比例 5:7）

| 区域     | 位置                              | 内容                                |
| -------- | --------------------------------- | ----------------------------------- |
| 状态区   | 左上三行 (y=8/26/44)              | SCORE / LEVEL / LINES 标签与数值    |
| NEXT 区  | 右上 (200,20) 起                  | NEXT 标签 + 4×4 迷你预览（格 12px） |
| 棋盘     | (8,64) 起，160×320                | 10×20 格，格 16px，2px 白墨描边     |
| 触屏控件 | 底部悬浮（覆盖于画布 392px 以下） | ◀ ▼ ▶ 一组；⟳ ⇓ 一组                |

- 画布以 CSS 拉伸至容器（容器比例由 manifest 声明），`image-rendering: pixelated` + `imageSmoothingEnabled=false` 保持像素锐利
- 幽灵块：当前方块落点以半透明轮廓显示（alpha 0.18）

## 5. 控件

- **键盘**：←→ 移动；↓ 软降；↑ / X 旋转；空格硬降；回车（结束态）重开。方向键与空格 `preventDefault`（防页面滚动）
- **触屏**：画布下方 DOM 按钮（◀ ▼ ▶ / ⟳ ⇓），`touch-action: manipulation`（防双击缩放），点击即响应
- **壳层**：暂停/继续/重开由 GameWindow 控制条调用 `GameInstance` 接口
- 暂停/结束时画布显示 PAUSED / GAME OVER 遮罩（双语，随界面语言）

## 7. 无障碍与生命周期

- 触屏按钮为真实 `<button>`（键盘可达、有 aria-label，双语）
- 销毁时清理：rAF、window keydown、DOM 节点全部移除（skill-code-review 维度 3）
- 游戏循环沿用固定时间步长 + 250ms 补帧上限（与 `games/shared/useGameLoop` 同纪律的引擎内实现）
