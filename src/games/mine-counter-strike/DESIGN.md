# 游戏级设计规范 · MineCounter-Strike（体素风 FPS）

> **版本**：v0.1
> **变更记录**：v0.1 初稿（随实现建立）
> **适用范围**：仅本游戏窗内（`src/games/mine-counter-strike/`）。窗外与窗框遵循网页级规范 `docs/design-language.md`。
> **依据**：用户指令（2026-08-15）——「Minecraft 体素风格射击游戏，至少五类枪械、可自定义角色皮肤、四张地图、腰射+开镜、1 真人 9 bot 5V5 团队死斗、单局 5 分钟、记录击杀助攻死亡、结算与排名、主界面换角色→选地图→30 秒选两把枪→切枪，操作参考传统射击游戏，命名 MineCounter-Strike」。

## 0. 技术方案（补充设计，非用户明示）

采用 **2.5D 射线投射（Raycasting）第一人称** 实现，理由与出处：

- 无需新增依赖（仓库无 three.js 等 3D 库；红线 6「新增依赖超出范围先问」）——纯 Canvas 2D 即可。
- 「腰射/开镜」与「传统射击游戏操作（WASD 移动 + 鼠标瞄准）」强暗示第一人称；射线投射是 Web 上实现第一人称最轻量的标准做法。
- 「Minecraft 体素风」由**像素化纹理墙 + 方块化角色/武器精灵 + `image-rendering: pixelated`** 落地。

> 本方案为**补充/推断**，已按红线 4 标注；若用户要求真 3D 或俯视角可回退重做。

## 1. 定位

- Minecraft 体素风 5V5 团队死斗 FPS；低分辨率逻辑画布 + 像素化拉伸，方块纹理墙、方块角色、方块枪械。
- 单局 5 分钟，击杀数定胜负；击杀/助攻/死亡三统计；终局结算 + 全 10 名玩家排名。
- 流程：主界面（换角色皮肤）→ 选地图 → 进入地图后 30 秒内选两把枪 → 战斗 → 结算。

## 2. 玩法规则（本文件即实现依据）

1. **人数**：10 名玩家 = 1 真人（A 队）+ 9 bot。A 队 5 人（真人 + 4 bot）、B 队 5 人（5 bot）。
2. **生命**：100 HP；归零死亡，3.0 秒后于本队出生点随机复活（团队死斗）。
3. **命中**：即时命中（hitscan）。沿枪口方向射线，先与敌人判定：横向角在散布+敌人体宽内、距离在射程内、且未被墙体遮挡者，取最近者受击。
4. **爆头**：瞄准俯仰落在敌人头部带内 → 伤害 × 武器爆头倍率（默认 ×2，狙击 ×2.5）。
5. **击杀/助攻/死亡**：击杀者 `kills+1`，被击杀者 `deaths+1`；死亡前 4 秒内对其造成过伤害、且非击杀者的其他玩家 `assists+1`。
6. **胜负**：5 分钟倒计时结束，**击杀总数多的一方获胜**；平局则判平（结算并列显示）。
7. **计分上报**：`callbacks.onScore(本人击杀数)`，由壳层提交 ScoreService（ADR-0005）；局终累计击杀经 `progressService.addKills` 入库（同 survivor-blacky 模式）。
8. **枪械**：玩家持**两把枪**，`1/2` 键或滚轮切换；主菜单/载入阶段选定两把；`R` 换弹；右键（按住）开镜 ADS、松开回腰射；左键射击（半自动点射 / 全自动连发）。
9. **载入阶段**：进入地图后 30 秒选枪（选满两把后可立即确认，或倒计时归零自动锁定默认「步枪 + 手枪」）；期间不判定战斗、计时冻结。

**未实现（明确排除，避免脑补）**：跳跃、下蹲、投掷物/手雷、护甲、经济/购买、拆弹/占领、脚步声/音效、语音、跨局胜场累计、网络联机、垂直多层地形（射线投射为单层平面）。

## 3. 状态机与流程（ADR-0007、决策 #24）

| 阶段（壳层） | 游戏内子状态          | 画面                            | 可选动作                                 |
| ------------ | --------------------- | ------------------------------- | ---------------------------------------- |
| `menu`       | `main`（换角色）      | 标题 + 皮肤选择 + 开始          | 切换皮肤 / [开始游戏] / 回车             |
| `menu`       | `maps`（选地图）      | 四张地图卡片                    | 选地图 / 返回                            |
| `playing`    | `loadout`（30s 选枪） | 已进入地图，枪械卡片 + 倒计时   | 点选两把枪 / [确认] / 倒计时归零自动锁定 |
| `playing`    | `combat`（战斗）      | 第一人称战斗 + HUD              | 全部玩法操作 / P 暂停 / Esc 释放鼠标     |
| `paused`     | —                     | 暂停面板                        | [继续] [重新开始] [返回主菜单]           |
| `over`       | `results`（结算）     | 胜负 + 10 人排名表 + 本人 K/A/D | [再来一局] [返回主菜单]                  |

- 阶段变化经 `callbacks.onPhase` 上报壳层；`mount` 后主动上报一次初始阶段。
- `再来一局`：保留皮肤与地图、回到 loadout 重开；`返回主菜单`：回到 menu/main。

## 7. 角色 / 机器人数值

| 项       | 值                                         |
| -------- | ------------------------------------------ |
| 生命     | 100                                        |
| 移动速度 | 3.2 单位/秒 × 枪械移速系数                 |
| 转身     | 真人：鼠标；bot：转向速度 3.0 rad/s        |
| 复活     | 3.0 秒                                     |
| 视野     | 真人 66.7°（腰射）/ 开镜缩放；bot 60° 锥形 |
| bot 反应 | 0.15~0.4s 锁定延迟（难度补偿）             |
| bot 精度 | 命中判定散布随距离增大（≈0.06 rad 起步）   |

> bot AI 为**补充设计**：巡逻 → 索敌（视线检测）→ 追击/射击；中等难度，保证可玩。

## 9. 控件

- **键盘**：W/A/S/D 移动；鼠标（指针锁定）转向，X 轴转朝向、Y 轴俯仰（shift 地平线）；左键射击；右键（按住）开镜；R 换弹；1/2 或滚轮切枪；P 暂停/继续；Esc 释放指针（再次点击画面重新锁定）。
- **触屏**：左半屏虚拟摇杆移动、右半屏拖动转向、`射击 / 开镜 / 换弹 / 切枪` 屏幕按钮（≥40px，§4.3）；开镜为按住切换。
- **壳层**：控制条随阶段适配（ADR-0007）：menu 隐藏暂停/重开；playing/paused 显示暂停/继续；over 隐藏暂停保留重开。
- 菜单浮层按钮为真实 `<button>`（键盘可达，双语 aria/文本）；方向/射击键 `preventDefault` 防页面滚动。

## 10. 工程结构与测试（决策 #25）

- `engine.ts`：纯逻辑（地图加载、移动碰撞、DDA 射线、命中判定、bot AI、计分、状态机、计时），无 DOM，可注入随机源。
- `engine.test.ts`：node 直跑冒烟测试——地图解析（四图非空且出生点齐）、角色初始化（1 真人 9 bot、5V5 分队）、枪械数值（5 类完整）、命中/击杀/助攻/死亡链路、DDA 射线遮挡、计时与胜负、换弹/切枪、确定性随机源。
- `render.ts`：Canvas 渲染（墙纹理/地板/精灵/武器/准星/HUD/小地图/击杀播报）。
- `Game.tsx`：输入 + 主循环 + 浮层 + GameInstance。

## 11. 无障碍与生命周期

- 菜单/控件为真实 `<button>`；焦点在按钮上时全局快捷键让位。
- 销毁时清理：rAF、pointer lock 监听、window 键盘/鼠标监听、DOM 节点全部移除。
- 高频回调（onScore）不触发壳层 effect 重建。
