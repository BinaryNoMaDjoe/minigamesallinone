## 1. 定位（不变，v1.1）

像素风自动战斗生存肉鸽：10 波限时生存 + 升级三选一 + 关底 BOSS。全部美术为代码手绘像素精灵。主角 = 罗小黑式黑猫。

## 2. 成长曲线设计（v1.2 核心，参考 VS/Brotato）

### 2.1 设计目标（收割爽感）

1. **前快后稳的升级节奏**：前 2 分钟 6-8 次升级，快速凑齐 3 把武器；后期升级放缓但每级仍可感知
2. **武器乘法成长**：单武器 5 级 DPS ≈ 1 级的 **6-8 倍**（每级伤害 ×1.4 + 数量/冷却断点）；六武器齐装满配 = 满屏弹幕
3. **进化爆发点**（VS 武器进化机制）：武器满级 + 配对被动满级 → **进化（Lv6）**，数值再 ×2-3 并强化机制，全屏白闪 + 巨大「进化！」弹字——中后期最强爽点
4. **怪多血薄**：出怪密度大幅上调，敌人 HP 曲线下调——波 5 后杂兵 1-2 击死、精英 3-4 击死，只有 BOSS 是肉；一局击杀 **800-1500+**（旧版约 300）
5. **被动叠乘**：伤害/攻速/暴击/拾取每级幅度上调，满级效果翻倍
6. **收割反馈**：连杀弹字（1.5s 内连杀 "×N"，越大越黄）、进化全屏闪、击杀粒子增强、暴击数字加大加叹号、大量击杀微震屏

### 2.2 升级经验（VS 式前快后稳）

- 升级经验 `5 + 3×(等级-1)`（Lv2 需 5，Lv10 需 32）
- 小鱼干改为**大珠制**：每敌只掉 1 颗，价值 = 该敌经验值（杂兵 2-6、精英 ×2、BOSS 60）——场上珠子少、磁吸一口肥，拾取更爽
- 场上小鱼干上限 300（超出最旧自动结算）；拾取半径 90（牛奶每级 +25%）

- 进化条件：武器满级（Lv5）**且**配对被动满级（Lv5），满足即自动进化（下次升级时结算，弹「进化！」全屏白闪 + 台词）
- 进化后武器不再出现在升级池；图标切换进化版（变色 + 星标）
- 攻击速度/伤害/暴击乘数对所有武器生效（含进化态）

### 2.5 敌人与波次（怪多血薄）

- 敌人 HP 缩放：`1 + 0.10×(波-1) + 0.04×分钟`（原 0.16/0.06）；伤害 `1 + 0.03×(波-1)`；移速 `1 + 0.02×(波-1)`
- 波次预算：`24 + 18×(N-1)`（W1 24 → W9 168）；出怪间隔 `max(0.24s, 0.9 - 0.07×(N-1))`；全场上限 320
- 精英概率：8% → 22% 递增（HP×2.6 / 伤害×1.6 / 经验×2 / 紫色描边+皇冠）
- 第 10 波 BOSS + 每 2.2 秒 2 只小怪补充流 + 开场 10 只本关代表怪

### 2.6 收割反馈（打击感规范）

- **连杀**：1.5s 窗口内连杀计数；×5 起在击杀位置弹「×N」黄字（每 +5 增字号）；连杀 ≥10 触发微震屏
- **进化**：全屏白闪 0.3s + 屏震 + 中央大弹字「进化! / EVOLVED!」+ 主角台词
- **暴击**：数字加大 + 「!」后缀 + 黄底墨影
- **击杀粒子**：按武器着色、数量随连杀增加（≤40/次）；BOSS 死亡粒子雨
- **普通命中**：白色 7px、暴击黄色 9px；数字上浮
