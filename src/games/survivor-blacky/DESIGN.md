# 游戏级设计规范 · 幸存者小黑（SurvivorBlacky · 像素风肉鸽）

> **版本**：v1.1
> **变更记录**：v1.0 初稿（2026-08-15，第三个正式游戏，随实现建立）→ v1.1（2026-08-15，用户反馈全面改造）：①修复弹窗画面显示不全——aspect 改 16:9、画布改宽驱动 + 固有比例（不依赖父容器高度解析）；②美术全量换为**代码绘制像素风**（Q 版原型参考：罗小黑黑猫/卡通粉猪/小鸡/柴犬/广场肥鸽，全部像素化）；③世界缩小为 960×540 单屏竞技场（土豆兄弟式全图视野，取消相机）；④补齐完整 UI：像素主界面（开始游戏/成就/玩法说明）、**成就系统**（12 个，经 ProgressService 持久化）、暂停/结算/升级卡全部像素化、成就解锁弹条
> **适用范围**：仅本游戏窗内（`src/games/survivor-blacky/`）。窗外与窗框遵循网页级规范 `docs/design-language.md`。
> **依据**：用户指令"为主站增加第三个游戏…名称 SurvivorBlacky"（2026-08-15）与用户反馈"美术太丑换成代码绘制像素、窗口画面只有一半、补齐主界面/开始/成就等全套界面"（2026-08-15）。

## 1. 定位

- **玩法**：吸血鬼幸存者式弹幕生存 + 土豆兄弟式单屏竞技场 + 自动武器构建——10 波限时生存、自动攻击、击杀掉落经验小鱼干、升级三选一、第 10 波 BOSS 战定胜负
- **美术**：**像素风**（pixel-art）——全部美术资产为代码手绘像素精灵（字符网格），`image-rendering: pixelated` 整数放大；字体 Press Start 2P（@fontsource 自托管）+ 中文字体回退栈；直角、4px 墨线、硬偏移阴影、无圆角无渐变
- **Q 版原型参考**（用户指定方向，全部像素化转绘）：主角 = 罗小黑式黑猫（大圆头黄眼白肚）；敌人 = 卡通粉猪、小鸡、柴犬、广场肥鸽；BOSS = 戴王冠披红披风的巨型鸽子王
- **主角**：小黑 Blacky——黑色像素小猫，黄色大眼睛 + 竖瞳 + 白色尾尖
- **幽默**：击杀拟声词（喵！BONK！呱！）、波次冷笑话命名、主角台词气泡、结算"死因报告"（例：你被猪拱了。）、搞笑成就（被猪拱了）
- **美术资产**：零外部图片素材，无版权风险

## 2. 玩法规则（本文件即实现依据）

### 2.1 世界与视角

- 世界 = 单屏竞技场 **960 × 540**，与画布 1:1（无相机、无缩放）；四周木栅栏围合
- 敌人从栅栏外随机边缘进入（先出现在栅栏外，再走进场内）；全场敌人上限 240

### 2.2 生存与波次

1. 一局共 **10 波**，每波 25 秒；第 10 波开始时 BOSS「鸽子王」入场，击杀 BOSS 即**胜利**；主角 HP 归零即**失败**
2. 波次预算：第 N 波（1-9）出怪总数 `18 + 12×(N-1)`；出怪间隔 `max(0.32s, 1.05 - 0.08×(N-1))`；波次切换未刷完预算并入下一波
3. 第 10 波：BOSS + 每 2.8 秒补 2 只小怪，开场附赠 10 只鸽子

### 2.3 主角

| 属性       | 初始值 | 说明                             |
| ---------- | ------ | -------------------------------- |
| 生命 HP    | 100    | 归零失败                         |
| 移速       | 165    | 像素/秒（单屏 960×540 尺度）     |
| 护甲       | 0      | 接触伤害先减护甲（减后至少 1）   |
| 伤害倍率   | 100%   | 所有武器伤害乘算                 |
| 暴击       | 5%     | 2 倍伤害                         |
| 拾取半径   | 90     | 经验小鱼干磁吸范围               |
| 经验倍率   | 100%   | 小鱼干经验乘算                   |
| 生命回复   | 0      | 每秒回复（仅来自「猫罐头」满级） |
| 受击无敌帧 | 0.75s  | 受伤后闪烁并免疫接触伤害         |

- 主角无手动攻击：全部武器自动瞄准/自动发射
- 移动：键盘 WASD/方向键（八向）；触屏：画布任意处按下拖动 = 虚拟摇杆

### 2.8 升级与经验

- 击杀掉落经验小鱼干（数量 = 敌人经验值）；场上小鱼干上限 500，超出最旧自动结算
- 升级经验 `6 + 4×等级`；升级后**冻结战场**弹出三选一（可叠加多个待选升级）
- 三选一池：未拥有武器（拥有 <2 把时权重上调）、已拥有武器升级、被动、血量 <65% 时的「小鱼干大餐：立即回复 35% 最大生命」。三个选项互不重复
- **新手保底**：前 3 次升级的三选一中至少出现一个新武器选项

### 2.9 计分与结算

- `得分 = 击杀数×10 + 存活秒数×1 + 已完成波次×50 + BOSS 击杀×500`
- 得分实时经 `callbacks.onScore` 上报壳层（ADR-0005）；主菜单展示最高分（经 scoreService 读取）
- 结算页：胜/败、存活时间、波次、击杀数、等级、得分、最高分、**死因报告**

### 2.10 幽默文案系统

- **击杀拟声词**：随机弹出（喵！/ BONK! / POW! / 呱！/ 叽！/ 汪！/ 嗝！…），0.9s 淡出
- **主角台词气泡**（冷却 12s）：开局"今天也要努力活到吃晚饭喵！"、BOSS 登场"……这只鸽子为什么戴着王冠？"、低血量（<30%）"喵命关天！"、升级"变强了喵！"、胜利"鸽子王也不过如此，晚饭加餐！"
- **死因报告**：被猪拱死 / 被鸡啄死 / 被狗追死 / 被鸽子踩扁 / 被鸽子王审判

**未实现（明确排除，避免脑补）**：音效与音乐、手柄支持、武器合成进化、局外养成/金币、暂停时保存进度、多地图、云存档。

## 5. 控件

- **键盘**：WASD / 方向键 移动（八向）；P 暂停/继续；升级浮层 1/2/3 直接选择、←→ 切换焦点 + 回车确认；回车/空格——menu 开始 / over 再来一局；Esc——成就/说明页返回主菜单；方向键与空格 `preventDefault`
- **触屏**：画布按下拖动 = 虚拟摇杆（`touch-action: none`）；升级/菜单为真实 DOM 按钮（≥40px）
- **壳层**：控制条随阶段适配（ADR-0007）：menu 隐藏暂停/重开；playing/paused 显示暂停/继续；over 隐藏暂停保留重开
- 升级浮层打开时战场冻结（引擎内部处理）；此时壳层暂停键为无操作

## 6. 屏幕与阶段状态机

游戏内屏幕 = 阶段 × 子屏：

| 阶段      | 子屏         | 内容                                                | 可选动作                              |
| --------- | ------------ | --------------------------------------------------- | ------------------------------------- |
| `menu`    | menu         | 像素布景（云/主角立绘/散步猪鸽）+ 大标题 + 菜单面板 | [开始游戏][成就][玩法说明] / 回车     |
| `menu`    | achievements | 12 个成就列表（图标/名称/描述/状态）+ 累计击杀      | [返回] / Esc·回车                     |
| `menu`    | howto        | 5 行玩法与操作说明                                  | [返回] / Esc·回车                     |
| `playing` | —            | 游戏进行（HUD 全显；升级时战场冻结三选一）          | 移动 / P 暂停 / 升级选择              |
| `paused`  | —            | 面板：已暂停                                        | [继续][重新开始][成就][返回主菜单]    |
| `over`    | —            | 胜利/失败 + 结算数据 + 死因报告                     | [再来一局][返回主菜单] / 回车再来一局 |

- 阶段变化经 `callbacks.onPhase` 通知壳层；`mount` 后主动上报一次初始阶段
- `重新开始` = 直接 `startRun()`：清空战场重新开局

## 8. 工程结构与测试（决策 #25）

- `engine.ts`：纯逻辑（世界/波次/武器/被动/敌人/升级/计分/事件流），无 DOM，可注入随机源，node 直跑
- `engine.test.ts`：冒烟测试——初始状态、开波刷怪、伤害击杀计分、升级三选一、被动叠加、受伤无敌帧、失败路径、波次推进、第 10 波 BOSS 与胜利路径、暂停/恢复、长时模拟无 NaN、确定性、自动风筝平衡模拟（信息性）
- `sprites.ts`：全部像素精灵资产（字符网格 + 调色板）
- `Game.tsx`：渲染与输入层（Canvas 960×540 + DOM 浮层）；精灵预渲染缓存；视觉粒子/拟声词/摇杆/成就判定仅存在于本层
- `src/services/progress.ts`：ProgressService 成就持久化
- 事件流：引擎产出 `GameEvent`（命中/击杀/爆炸/波次/升级/台词…），Game 每帧 `drainEvents()` 消费为视觉
