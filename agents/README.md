# agents/ — 角色化代理定义

> **版本**：v0.1
> **变更记录**：v0.1 初稿（2026-08-15）

## 是什么

本目录存放可复用的**代理角色定义**（提示词模板）。开启子代理时，将对应文件的全部内容作为角色指令传入，并要求其**先读 `AGENTS.md`** 再动手。

| 代理 | 文件 | 职责 |
|---|---|---|
| game-dev | `game-dev.md` | 按 skill-add-game 开发单个游戏 |
| ui-dev | `ui-dev.md` | 大厅/弹窗壳层/公共组件开发 |
| reviewer | `reviewer.md` | 对照规范审查变更 |

## 共同约束

- 所有代理必须遵守 `AGENTS.md` 红线与工作流
- 输出必须可溯源（每条结论给出文档出处）；无出处的判断标「待确认」
- 代理不得修改宪法级文档（design-language.md、AGENTS.md、process 规范）；有意见 → 提生长提案
- 代理定义本身可随项目生长（修订需更新版本与变更记录）
